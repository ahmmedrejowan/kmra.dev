# Getting help

- **How do I…?** Start with the [wiki](https://github.com/ahmmedrejowan/kmra.dev/wiki): Simple and
  Advanced modes, batches, privacy, offline use and common questions.
- **A question the wiki doesn't answer:** ask in
  [Discussions](https://github.com/ahmmedrejowan/kmra.dev/discussions/categories/q-a).
- **Something doesn't work:** [report a bug](https://github.com/ahmmedrejowan/kmra.dev/issues/new?template=bug_report.yml).
- **An idea for a tool:** [suggest it](https://github.com/ahmmedrejowan/kmra.dev/issues/new?template=feature_request.yml).
- **A security problem:** [report it privately](https://github.com/ahmmedrejowan/kmra.dev/security/advisories/new)
  or email ping@kmra.dev.
